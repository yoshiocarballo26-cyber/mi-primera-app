# Editandroid — inicio de YC Editor 3D para Android

Primer prototipo Android de **YC Editor 3D**.

La app es un contenedor Android ligero que abre la versión web de YC Editor 3D alojada en GitHub Pages. La compilación se realiza en GitHub Actions para no cargar el Chromebook con Android Studio ni el SDK completo.

## Estado
- Version: 0.1.0
- Application ID: com.yc.editor3d.android
- Web app: https://yoshiocarballo26-cyber.github.io/Scaner3D/
- Build: GitHub Actions
- APK de prueba: artifact de cada ejecución del workflow
